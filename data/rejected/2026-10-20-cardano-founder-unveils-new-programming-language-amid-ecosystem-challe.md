# Cardano Founder Unveils New Programming Language Amid Ecosystem Challenges

Cardano founder Charles Hoskinson has announced the development of a new programming language aimed at enhancing the blockchain's transaction capabilities. However, this technical update comes at a time when the network faces ongoing challenges in attracting total value locked (TVL) and commercial usage compared to competing layer-1 platforms.

According to a report by [CryptoSlate](https://cryptoslate.com/hoskinson-reveals-new-code-for-cardano-but-63m-tvl-exposes-a-gap/), Hoskinson revealed that he is working alongside developer Lucas Rosa, a software engineer at Input Output Global (IOG). The collaborative effort is focused on building a new programming language designed specifically to support intent-based transactions and proof-carrying data on the Cardano network.

This technical initiative utilizes Groth16 cryptographic proofs to improve how transactions are processed and verified. The announcement underscores Cardano's continued focus on cryptographic research and infrastructure development as the project navigates its broader development roadmap.

## Intent-Based Architecture and Cryptographic Proofs

The proposed programming language focuses on intent-based transactions, an architectural paradigm in blockchain development that allows users to specify desired outcomes rather than executing explicit, step-by-step transaction instructions. By pairing this framework with Groth16 cryptographic proofs, the language aims to support proof-carrying data, which can verify computational state transitions efficiently.

Lucas Rosa, a software engineer at Input Output Global—the primary research and engineering entity behind Cardano—is collaborating directly with Hoskinson on the codebase. While specific technical details regarding a public deployment timeline remain limited, the project represents another step in IOG's ongoing efforts to expand the smart contract, transactional, and architectural capabilities of the Cardano ecosystem.

## Technical Progress Versus DeFi Market Adoption

Despite the rollout of new code and research-driven updates, Cardano exhibits a noticeable gap between its core technical development and its current commercial adoption. Data reported by [CryptoSlate](https://cryptoslate.com/hoskinson-reveals-new-code-for-cardano-but-63m-tvl-exposes-a-gap/) highlights that Cardano's decentralized finance (DeFi) ecosystem currently holds approximately $63 million in total value locked (TVL).

Total value locked measures the overall amount of capital committed to a blockchain's smart contracts, protocols, and decentralized applications. A TVL figure of $63 million illustrates a key challenge for the ecosystem: while research and core infrastructure developments continue to move forward, capital deployment and active user engagement on decentralized applications remain constrained relative to developer activity.

As Cardano faces ongoing market competition, the contrast between developer output and locked capital emphasizes the platform's need to translate underlying infrastructure improvements into active application usage and broader financial liquidity.

## Implications for Developers and Ecosystem Growth

The introduction of an intent-based programming language leveraging Groth16 proofs is intended to make application development on Cardano more versatile. Intent-based frameworks are designed to simplify user interactions by allowing specialized off-chain actors to manage complex transaction routing, which can streamline activities like decentralized exchange trades and multi-step smart contract interactions.

However, the ultimate impact of these technical updates depends on developer adoption. Implementing new programming paradigms requires decentralized application developers to adapt to new tooling and smart contract architectures. If widely adopted, the framework could provide a structural foundation that addresses performance and usability considerations. Conversely, if developer adoption lags, the divergence between Cardano's research updates and its operational DeFi metrics, such as TVL, may persist.

As of October 20, 2026, the joint development effort between Hoskinson and Rosa remains actively underway at Input Output Global, with further technical details expected as the codebase matures.
